rachne Plus
A Fabric mod for Minecraft 26.2 that makes fighting the Arachne miniboss on Hypixel Skyblock easier.
For Arachne Lovers, By Arachne Lovers
Website: https://arachneplus.com
Modrinth: https://modrinth.com/mod/arachne-plus
Discord: https://discord.gg/5yh3sJGTw
Features
Phase display: shows which of the 5 phases you are in
Brood counter: broods left in the brood phases, green to red as they die
Placer alert: a big PLACE alert when 5 or fewer broods are left in the second brood phase
Glow and boss line: every Arachne spider glows through walls, with a line pointing at the main boss
Timers: boss timer, average, last and best kill time, and an altar spawn countdown
Profit tracker: coins and spider essence per boss and per session
Party commands: teammates type commands like `!kills`, `!pb`, `!top` or `!gyro` in party chat
Player lookup and leaderboard: kills, stats and global rankings
Achievements
CPS counter
Settings screen and drag-and-drop HUD editor (press Right Shift)
Install
Easiest: download the finished mod
Download the latest jar from Modrinth or the Releases page here, and put it in your `mods` folder together with Fabric API for 26.2.
Build it yourself
Install Java 25 (JDK).
Windows: double-click `build-windows.bat`. Mac/Linux: run `./build-mac-linux.sh`.
The finished jar is in `build/libs`.
Full steps are in `INSTALL - READ ME FIRST.txt`.
In game
Right Shift opens the settings screen.
Some lookups need a Hypixel API key from https://developer.hypixel.net. Type `/apapikey YOUR_KEY`, or use the "API key" button in the settings screen.
